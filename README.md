# 数学弹球闯关（Math Ball Arena）

自动演示型数学闯关小游戏。玩家只在开局选一颗「公式球」，之后全程无需操作：
小球在屏障上反复弹跳，每次碰撞公式升阶、伤害按公式爆炸增长；屏幕顶部一整排尖刺匀速下落，
就是可视化的时间限制。尖刺触球即失败，穿过一关的 3 道屏障落入底部安全区即过关。

**核心设定：9 关本质是同一条成长曲线被切成 9 段。**

- 小球的阶数 **跨关累加**，第 9 关是第 1 关的延续，不重置（实测 `n: 2 → 168`）
- 27 道屏障的血量指数 **全局严格递增**，终点锁定 **10³⁰⁰**
- 关卡之间 **无缝衔接**：不停顿、不弹结算界面，只闪一下关卡号
- 球上 **固定显示公式符号本身**（`n!` / `T(n)!` / `(n²)!`），不显示具体阶数，永不溢出
- 后端 Java 17 + Spring Boot 3 下发关卡配置，前端原生 HTML5/Canvas，零构建链

---

## 快速开始

前置：**JDK 17+**、Maven 3.9+

```powershell
.\mvnw.ps1 test              # 跑后端单元测试
.\mvnw.ps1 spring-boot:run   # 启动，浏览器打开 http://localhost:8080
```

`mvnw.ps1` 做两件事：自动挑选一个 JDK 17+（本机 `JAVA_HOME` 可能指向 JDK 8），
以及把 Maven 本地仓库固定到项目内的 `.m2repo/`（避免写用户目录被沙箱拒绝）。

调试面板：`http://localhost:8080/?debug=1` —— 实时显示当前阶数、撞击计数、尖刺位置。

## 玩法

```
选球 → 第1关 → (破碎3道屏障) → 无缝进入第2关 → … → 第9关 → 通关界面
                    ↓尖刺触球
                 失败界面
```

- 小球每与屏障碰撞一次，阶数按该球种固定的步长增加，伤害 = 升阶后公式的运算结果
- 伤害 < 10⁶ 用千分位，≥ 10⁶ 用科学计数法（`2.95×10³⁸`）
- 结束界面（通关 / 失败）只有数据、**没有任何按钮**，点击空白处返回选球界面

三种公式球（步长是球种固有属性，开局定死、全程不可调）：

| 球种 | 公式 | 固定步长 | 定位 |
|---|---|---|---|
| 阶乘球 | `n!` | 每击 +2 | 最弱，最慢（83 击通关） |
| 三角阶乘球 | `T(n)!` | 每击 +1 | 进阶（27 击通关） |
| 正方阶乘球 | `(n²)!` | 每击 +1 | 最强（27 击通关，伤害溢出更多） |

## 数值设计

| 关 | 屏障 1 | 屏障 2 | 屏障 3 | 尖刺速度 |
|---|---|---|---|---|
| 1 | 10⁴ | 10¹⁰ | 10¹⁸ | 52 px/s |
| 2 | 10²⁷ | 10³⁶ | 10⁴⁵ | 55 px/s |
| 3 | 10⁵⁵ | 10⁶⁶ | 10⁷⁶ | 58 px/s |
| 4 | 10⁸⁷ | 10⁹⁸ | 10¹¹⁰ | 61 px/s |
| 5 | 10¹²¹ | 10¹³³ | 10¹⁴⁵ | 64 px/s |
| 6 | 10¹⁵⁷ | 10¹⁷⁰ | 10¹⁸² | 67 px/s |
| 7 | 10¹⁹⁵ | 10²⁰⁷ | 10²²⁰ | 70 px/s |
| 8 | 10²³³ | 10²⁴⁷ | 10²⁶⁰ | 76 px/s |
| 9 | 10²⁷³ | 10²⁸⁷ | **10³⁰⁰** | 82 px/s |

曲线由 `tools/design-levels.mjs` 生成：以阶乘球（每击 +2）每 3 击推进一道屏障为节奏基准，
取每段累积伤害的量级，再平滑拉伸到终点 10³⁰⁰。

实测表现（真机逐帧模拟，与浏览器内运行结果一致）：

| 球种 | 每关击数 | 整局时长 | 终球 |
|---|---|---|---|
| 阶乘球 (+2) | 9~10 击 | **50.9s** | 168! |
| 三角阶乘球 (+1) | 3~4 击 | **23.8s** | 30! |
| 正方阶乘球 (+1) | 3 击 | **23.3s** | 29! |

## 数值验证工具（改任何物理参数后必须全部重跑）

```powershell
node tools/design-levels.mjs     # 生成血量曲线：27 道屏障全局严格递增，终点 10^300
node tools/calibrate.mjs         # 二分搜索每关临界尖刺速度（必须按 1→9 关连续推进）
node tools/physics-selftest.mjs  # 连续跑完 9 关，验证跨关累加、整局时长、物理不变量
node tools/syntax-check.mjs      # 前端模块加载 + 数值格式化边界
node tools/api-check.mjs         # 接口契约（需先启动服务）
```

⚠️ **两个容易踩的坑：**

1. **千万不要用解析公式估算限时。** 尖刺的触发点是「小球在屏障 1 上弹跳到最高点时的球顶」，
   不是「尖刺走满画布」；而且小球会随关卡推进下落到更低的屏障，可用时间随之变长。
   早期版本用"均匀行程"近似，导致多关判定全部算错。
2. **标定必须按第 1 关 → 第 9 关的顺序连续推进。** 因为阶数跨关累加，
   每关的起始 n 取决于上一关的结束 n，不存在"独立标定某一关"这回事。

### 修改物理参数的标准流程

1. 改 `src/main/resources/application.yml` 的 `mathball.physics`
2. 同步 `src/main/resources/static/js/config.js` 的 `PHYSICS_DEFAULTS`
3. 跑 `node tools/physics-selftest.mjs`，确认三种球都还能通关

---

## ⚠️ 关于「重力球」

`js/traits.js` 里预留了 `gravity` 钩子（每次碰撞后 `gravityMul *= 1.06`），但 **v1 未启用**。

原因：重力 `g` 一旦变化，弹跳高度 `v0²/2g` 与弹跳周期 `2v0/g` 全部改变，
上表所有尖刺速度立刻失效。**启用任何改变 `g` 或 `v0` 的球种前，必须重跑上面的标定流程。**

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/levels` | 9 关配置 + 物理常量 + 过场配置 |
| GET | `/api/levels/{n}` | 单关配置 |
| GET | `/api/balls` | 公式球清单 |
| POST | `/api/runs` | 上报战报 |
| GET | `/api/runs/best` | 最佳成绩 |

血量以**十进制字符串**下发（`10^300` 会超出 JSON number 精度）。
每关还附带 `formulaCheck`，前端启动时用本地 BigInt 重算比对，防止前后端公式实现漂移。
