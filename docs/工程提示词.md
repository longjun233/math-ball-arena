## 0. 交付目标

做一个**自动演示型**数学闯关小游戏：玩家只在开局选一种「公式球」，之后全程无需操作。小球在屏障上反复弹跳，每次碰撞公式升阶、伤害按公式爆炸增长；屏幕顶部一整排尖刺匀速下落，是可视化的时间限制。尖刺触球即失败；穿过一关的 3 道屏障落入底部安全区即过关，直接进入下一关；9 关全部通过显示通关界面。

**交付物**：
1. Spring Boot 后端（下发关卡配置、托管前端、接收战报）
2. Canvas 前端（零构建，原生 ES Module）
3. 可运行 demo：`mvn spring-boot:run` 后浏览器打开即玩
4. Git 仓库，规范提交

## 4. 关卡数值表（唯一真值，直接抄进 `levels.yml`）

**本版的根本变化：小球阶数跨关累加，9 关是同一条成长曲线被切成 9 段。**

因此 27 道屏障的血量指数必须【全局严格递增】——不允许出现「第 8 关第 3 道 10^150
而第 9 关第 1 道 10^100」这种关卡间倒挂。

| 关 | 屏障 1 | 屏障 2 | 屏障 3 | 尖刺速度 |
|---|---|---|---|---|
| 1 | 10^4 | 10^10 | 10^18 | 52 px/s |
| 2 | 10^27 | 10^36 | 10^45 | 55 px/s |
| 3 | 10^55 | 10^66 | 10^76 | 58 px/s |
| 4 | 10^87 | 10^98 | 10^110 | 61 px/s |
| 5 | 10^121 | 10^133 | 10^145 | 64 px/s |
| 6 | 10^157 | 10^170 | 10^182 | 67 px/s |
| 7 | 10^195 | 10^207 | 10^220 | 70 px/s |
| 8 | 10^233 | 10^247 | 10^260 | 76 px/s |
| 9 | 10^273 | 10^287 | **10^300** | 82 px/s |

曲线由 [tools/design-levels.mjs](<C:\dsh  GZQ\math-ball-arena\tools\design-levels.mjs>)
生成：以阶乘球（每击 +2）**每 3 击推进一道屏障**为节奏基准，取每段累积伤害的量级作为该道
屏障的血量指数，再平滑拉伸到终点 10^300。

第 9 关第 3 道屏障**必须是 10^300**，这是硬约束。

> **尖刺速度必须用 `tools/calibrate.mjs` 标定，不能拍脑袋。**
> 尖刺的触发点是「小球在屏障 1 上弹跳到最高点时的球顶」，不是「尖刺走满画布」；
> 而且标定必须按第 1 关 → 第 9 关的顺序连续推进，因为每关的起始 n 取决于上一关的结束 n。
> 当前速度按 52 → 82 px/s 平滑递增，实测余量 k = 1.97 → 1.25。

### 4.1 期望行为矩阵（回归基准，由 `tools/physics-selftest.mjs` 真机验证）

| 球种 | 每关击数 | 单关耗时 | 整局时长 | 终球 |
|---|---|---|---|---|
| 阶乘球 `n!` (+2) | 9~10 击 | 5.54~6.03s | **50.9s** | n=168 |
| 三角阶乘球 `T(n)!` (+1) | 3~4 击 | 2.59~3.08s | **23.8s** | n=30 |
| 正方阶乘球 `(n²)!` (+1) | 3 击 | 2.59s | **23.3s** | n=29 |

三种球都能通关，**阶乘球是最慢的那个**——这就是「它是最弱球种」在连续成长模型下的体现：
同样的血量，它要撞 83 次，三角阶乘球只要 27 次。

阶数跨关累加轨迹（阶乘球）：`n: 2 → 20 → 40 → 58 → 76 → 94 → 112 → 132 → 150 → 168`

整局时长必须 ≤ 2 分钟，当前三种球都落在 23~51s。

## 5. 公式球定义

```java
public enum BallFormula {
    FACTORIAL("阶乘球",     "n!",     2),   // f(n) = n!
    TRI      ("三角阶乘球", "T(n)!",  1),   // f(n) = T(n)!, T(n)=n(n+1)/2
    SQR      ("正方阶乘球", "(n²)!",  1);   // f(n) = (n²)!
}
```

**规则**
- `step` 是球种的**固有属性**，开局选球即确定，**全程恒定、不随关卡变化、玩家不可调整**。
- 小球初始阶数 `n = 2`（显示 `2!`）。
- 碰撞结算顺序：**先升阶，后结算伤害**。即 `n += step; damage = f(n);` 然后扣屏障血量。
- 全部运算使用 `java.math.BigInteger`（后端）/ `BigInt`（前端）。**禁止**出现 `long` / `double` 参与伤害与血量计算。
- 新增球种只需加枚举值 + 公式 + 步长，**不得改动关卡血量表**。

## 6. 物理规格

### 6.1 常量

| 参数 | 值 |
|---|---|
| 画布 | 900 × 760 |
| 重力 `g` | 1700 px/s²（放慢节奏；原 2400 手感偏快） |
| 反弹垂直速度 `v0` | 420 px/s（**固定**） |
| 反弹水平速度 `vx` | `randomSign() × uniform(40, 160)` px/s（**随机**） |
| 弹跳高度 `h = v0²/2g` | 51.88 px（恒定，校验用） |
| 弹跳周期 `T = 2v0/g` | 0.494 s（恒定，校验用） |
| 屏障间距 | 110 px |
| 屏障厚度 | 16 px |
| 屏障 y | 390 / 500 / 610，**x 覆盖 0~900 全宽** |
| 小球半径 | 16 px，初始位置 (450, 100)，`vx=vy=0` |
| 底部安全区 | `ball.y - r > 670` |
| 尖刺 | 高 60 px，初始顶部 y = -60，底边从 y = 0 起，恒定速度下落，行程 700 |
| 物理步长 | 固定 `1/120` s |
| 左右墙 | 实体墙，`x < r` 或 `x > 900-r` 时 `vx = -vx` 并夹紧位置 |

### 6.2 每帧算法（伪代码，必须按此顺序）

```
onFrame(dtSeconds):
  1. dt = min(dtSeconds, 0.1)                        // 钳制，防切后台跳变
  2. accumulator += dt
  3. while accumulator >= FIXED_STEP:
       stepPhysics(FIXED_STEP)
       accumulator -= FIXED_STEP
  4. render()

stepPhysics(dt):
  if state != RUNNING: return

  // 小球
  ball.vy += g * gravityMul * dt
  ball.x  += ball.vx * dt
  ball.y  += ball.vy * dt

  // 左右墙
  if ball.x - r < 0:      ball.x = r;      ball.vx = -ball.vx
  if ball.x + r > W:      ball.x = W - r;  ball.vx = -ball.vx

  // 尖刺
  spike.y += spikeSpeed * dt
  if spike.y + spikeHeight >= ball.y - r: state = GAME_OVER

  // 屏障碰撞（只检测当前未破碎的最低一道屏障）
  bar = currentBarrier()
  if bar != null and ball.vy > 0 and hitCooldown <= 0
     and circleIntersectsRect(ball, bar):
        ball.y = bar.top - r                  // 位置修正
        ball.vy = -v0                         // 垂直分量固定
        ball.vx = randomSign() * uniform(40,160)   // 水平分量随机
        hitCooldown = 0.06
        traits[currentBall].onHit(ball)       // 预留钩子，v1 为空
        ball.n += ball.step
        damage = f(ball.n)
        bar.hp -= damage
        emit HIT event(bar, damage, ball.n)
        if bar.hp <= 0: emit BREAK event(bar)

  hitCooldown -= dt

  // 通关
  if ball.y - r > safeZoneTop: state = LEVEL_CLEAR
```

### 6.3 不变量（**必须写成断言/单测**）

1. `v0² / (2g) < 0.6 × 屏障间距`（51.88 < 66 ✅）—— 否则小球会撞到上一道屏障。
2. 弹跳周期 `2v0/g` 与水平速度无关 —— 水平运动与垂直运动解耦。
3. 撞击后 `vy` 恒为 `-420`，不随入射速度变化（这就是"弹性固定"）。
4. 小球永远满足 `r ≤ x ≤ W-r`，且永不从屏障侧边漏下（屏障全宽）。
5. 每次撞击的 `damage` 只由 `n` 与球种决定，与屏障血量无关。

## 7. 关卡与状态机

```
HOME ──点击球卡片──> RUNNING(1)
RUNNING(n)
   ├─ 尖刺触球 ─────────> GAME_OVER
   └─ 落入安全区
        ├─ n < 9 ─> 立即 RUNNING(n+1)：小球瞬移回 (450,100)、vy=0、vx=0，
        │            屏障刷新为下一关，尖刺重置到顶部，
        │            **阶数 n 原样带入下一关**（跨关累加，不重置）
        │            画面只闪一下关卡号，不暂停、不弹结算界面
        └─ n = 9 ─> ALL_CLEAR

GAME_OVER / ALL_CLEAR  [纯数据显示，无任何按钮]
   └─ 点击遮罩任意处 ─> HOME
```

**硬性要求**
- 过关**绝对不能弹结算界面**，只能走 `NEXT_LEVEL` 的 0.6s 过场。
- 每关开始时小球必须回到初始位置与初始阶数 `n=2`。
- `GAME_OVER` / `ALL_CLEAR` 界面上**不得出现任何 `<button>` 或可点击控件**，只能整屏响应点击。

### 8.2 伤害格式化函数（必须完全一致）

```
formatDamage(d: BigInt) -> string
  s = d.toString()
  if s.length <= 6:            // < 1,000,000
      return 千分位(s)          // 362880 -> "362,880"
  else:                        // >= 1,000,000
      e = s.length - 1
      mantissa = Number(s.slice(0,4)) / 1000     // 保留 3 位有效数字
      return `${mantissa.toFixed(2)}×10^${e}`    // 479001600 -> "4.79×10^8"
```

示例：`720` → `720`；`362880` → `362,880`；`479001600` → `4.79×10^8`；`10^300` 量级伤害 → `1.40×10^304`。

## 11. 必须实现的自检

1. **前端启动自检**：拿 `/api/levels` 的 `formulaCheck`，用本地 `BigInt` 公式重算前 4 次撞击的伤害与累积，不一致则 `console.error` + 屏幕角落红色告警。
2. **血量指数自检**：加载配置时断言每关 `hp[0] < hp[1] < hp[2]`。
3. **物理常量自检**：断言 `v0²/(2g) < 0.6 × barrierGap`、屏障数恰为 3、`vxMin ≤ vxMax`。
4. **数值与门槛回归**：见 §12。

## 13. 禁令

1. **不要**把伤害或血量算在 `long` / `double` 上。
2. **不要**把 `10^300` 写进 JSON 数字字段（必须字符串）。
3. **不要**让升阶步长随关卡变化。
4. **不要**用"衰减弹性系数"（`v' = e·v`），必须用固定反弹速度。
5. **不要**用真随机角度（会破坏垂直分量），必须固定 `vy`、只随机 `vx`。
6. **不要**在过关时插入任何带数据或按钮的界面。
7. **不要**在结束界面放按钮。
8. **不要**为避免"一击破屏"而调高血量 —— 强球一击破屏是预期观感。
9. **不要**改动关卡血量表后不重跑 `balance-calc.mjs`。
10. **不要**引入前端框架或 Node 构建链。
